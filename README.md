## The fortune

> A margin call will wake you at 3am; your 100x leverage now buys exactly one fortune cookie.

One line, 17 words, 91 characters — a fortune-cookie fortune for a crypto trader who just got liquidated. The margin call, the 3am wake-up, the 100x leverage: all that's left of it buys the very cookie delivering the news.

## Run

```sh
ENTRY_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```

`main.py` is stdlib only, makes no network calls, and is deterministic: two runs produce byte-identical output.
